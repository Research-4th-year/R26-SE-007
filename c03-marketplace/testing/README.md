# C03 Marketplace — Testing Evidence

This folder stores PP2 testing documentation and evidence only.

It does **not** contain application source code, automated test suites, or project configuration.

## Folder purpose

### `unit/`

- Unit test cases
- Unit test results
- Screenshots and other evidence
- Notes about individual functions or components

### `integration/`

- Integration test cases
- Evidence of frontend, backend, API, and database integration
- Test results and screenshots

### `system/`

- End-to-end / system testing
- Complete user-flow test evidence
- Screenshots and test results

### `nfr/`

- Non-functional requirement testing
- Performance and response-time measurements
- Usability and accessibility observations
- Reliability and security-related evidence where applicable

### `regression/`

- Bug-fix testing
- Regression test cases
- Before/after evidence
- Notes confirming previously working functionality still works after fixes
